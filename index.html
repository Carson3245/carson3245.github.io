02 — SAÍDA FÁCILSoftware Development

Saída Fácil

Aplicativo Android para consultar produtos, registrar saídas e acompanhar contagens e movimentações de estoque.

Estudo de caso

O app usa um contêiner Android em Java com WebView e interface HTML, CSS e JavaScript compartilhada. Uma API local conecta o celular à planilha de estoque e registra movimentações.

AndroidJavaWebViewJavaScriptHTML/CSS
03 — CHECKLIST FÁCILSoftware Development

Checklist Fácil

Aplicativo para conferir expectativas de venda e organizar a produção antes de enviar itens aprovados ao estoque.

Estudo de caso

O fluxo confirma a expectativa, apresenta uma prévia calculada e deixa a revisão das quantidades com o gerente. Só os itens selecionados seguem para o estoque; o registro de sobras fica separado.

AndroidJavaWebViewJavaScriptHTML/CSS
04 — CASA DE LEILÕESSoftware Development

Casa de Leilões

Aplicação desktop em Java Swing para cadastrar e consultar itens de um leilão.

Estudo de caso

As telas separam cadastro e listagem; um DAO concentra as operações JDBC de inserção e consulta dos produtos.

JavaSwingDAOJDBC
